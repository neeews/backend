# 중요도 판단 예시

사람이 정답지를 매길 때 옆에 두고 보는 예시 모음이다.
분석과 검증 방법은 [LABELING_GUIDE.md](./LABELING_GUIDE.md)에 있다.

**라벨은 두 개만 쓴다. `HIGH`(중요) 또는 `LOW`(안 중요).** MEDIUM은 쓰지 않는다.

---

## 질문 하나

> **오늘 이 기사를 놓치면 독자가 손해를 보는가?**

예 → HIGH, 아니오 → LOW. 사건이 큰지, 클릭이 많은지를 묻는 게 아니다.

---

## 읽지 않고 LOW

| 형태 | 예 |
|---|---|
| 말머리 | `[게시판]` `[부고]` `[동정]` `[인사]` `[신간]` `[내일날씨]` `[헤드라인]` `[건강포커스]`, 번호 붙은 연재물 |
| 지자체 보도자료 | `○○시, ~ 모집 / 개최 / 운영 / 지원 / 착공` |
| 협약 단계 | `A사-B사, 업무협약(MOU) 체결` |
| 증권사 코멘트 | `○○증권, ○○ 목표주가 상향` |
| 주가 등락 | `[특징주] ~ 상승 중` |

---

## HIGH 예시

| 기사 | 왜 |
|---|---|
| `환율 1년 2개월만에 1,350원대` | 전 국민 자산에 닿는다 |
| `한은, 외환보유액 순위 25년 만에 비공개` | 국가 단위 사안 |
| `법원, 홈플러스 회생계획안 인가` | 확정됐고 되돌릴 수 없다 |
| `인천 아파트서 난간 작업하던 노동자 2명 추락해 숨져` | 사망 사고 |
| `美 '반도체 표적관세'` | 수출기업이 오늘 판단을 바꿔야 한다 |
| `국민연금 추납 제도 전면 개편 추진` | 아직 "추진"이지만 내 돈이 바뀐다 |
| `9월 모평, 국어·수학은 6월보다 어려웠다` | 수험생 진로 판단이 바뀐다 |
| `부산 예인선 사고, 밤새 수색에도 실종자 못 찾아` | 내일도 이어진다 |
| `한화오션, LNG선 6척 수주…1조 5527억원` | 조 단위는 산업 전체 신호 |

## LOW 예시

| 기사 | 왜 |
|---|---|
| `삼척시, 다자녀 가정 대학등록금 최대 100만 원 지원` | 한 지자체에 그친다 |
| `미래운용-방통대, 대학기금 MOU` | 협약일 뿐 벌어진 일이 없다 |
| `경기 광주시, 종합장사시설 후보지 '연말 결정'` | 아직 안 정해졌다 |
| `오리온, '포카칩 황치즈맛' 출시` | 신제품 소식 |
| `시흥서 비탈길 미끄러진 '빈 트럭', 승용차와 충돌` | 인명피해가 없다 |
| `이창동 감독, 밀밸리 영화제 '어터상' 수상` | 하루짜리 단발 |
| `김민재 3경기 연속 선발, 뮌헨 4-1 대승` | 경기 결과 |
| `조선 왕실 불경·오십삼불 그림, 보물 된다` | 확정된 결정이지만 독자가 달라질 게 없다 |
| `경기도 지역응급의료센터 36곳으로 확대` | 광역 단위, 전국은 아니다 |

## 갈리는 것들

**`한화오션 1조 5527억원 수주` = HIGH / `[특징주] 알테오젠, 4.4조원 계약 소식에 강세` = LOW**
둘 다 조 단위인데 갈린다. 뒤엣것은 **주가가 움직였다는 기사**다. 계약 자체를 다룬 기사가 따로 들어오면 그건 HIGH다.

**`다세대주택 화재, 80대 의식 저하 이송` = LOW**
인명피해가 있지만 사망이 아니고 국지적이다. **사망·실종이면 HIGH, 부상까지면 LOW**로 가른다.

**`국민연금 추납 개편 추진` = HIGH인데 `장사시설 후보지 연말 결정` = LOW**
둘 다 아직 안 정해졌다. 차이는 **내 돈·자격·의무가 직접 바뀌느냐**다. 관공서 발표문처럼 생겼다고 눌러서는 안 된다.

**같은 사건이 여러 건 들어오면 대표 1건만 HIGH.**
`(종합)`이나 마지막 보를 고르고 나머지는 LOW. 안 그러면 그 사건이 학습 데이터에서 과대대표된다.

---

## 판단이 안 설 때 보는 신호

두 개 이상 걸리면 HIGH 쪽이다.

- **전국 단위 이상인가** — 특정 지자체·개별 기업·개인에 그치면 아니다
- **이미 벌어졌는가** — 사망, 선고, 확정, 대규모 해고. 예정·검토는 아니다
- **독자가 오늘 다르게 행동해야 하는가** — 돈·안전·진로
- **내일도 이어지는가** — 후속 보도가 예상되는가

여러 매체가 동시에 붙었다는 사실(24시간 내 같은 사건 10건 이상)은 **위 신호가 이미 하나 이상 걸렸을 때만** 근거로 쓴다. 가십도 보도량은 많다.

---

## 두 가지만 지킨다

**HIGH가 100건 중 10~15건이면 정상이다.** 적다고 억지로 늘리지 않는다.

**며칠 뒤 20건을 `round=1`로 다시 매긴다.** 자기 자신과 80% 미만이면 기준이 흔들린다는 뜻이라 그 정답지로는 모델을 채점할 수 없다.

```
GET  /admin/labeling/next?size=20&filter=NO_SEED
POST /admin/labeling/{articleId}   { "label": "HIGH", "round": 0 }
```
